# Team and roles

Invite colleagues from **Team** in the dashboard. They get an email invitation and join your account.

| Role | Access |
| --- | --- |
| **Owner** | Full access, including billing, subscription plans, team, API keys and audit logs. |
| **Admin** | Full access, including billing, subscription plans, team, API keys and audit logs. |
| **Editor** | Banner Builder, Cookie Manager, script blocking, installation code and the policy generator, plus everything a viewer sees. |
| **Viewer** | Dashboard, websites, analytics, compliance pages and consent records, read only. |

## Audit logs

**Audit logs** (Owner and Admin) record who changed what in the account.

When someone leaves, remove them from the team and rotate any API keys they could have copied.
